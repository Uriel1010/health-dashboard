# Documentation screenshots

These PNG files show the repository's actual compiled React frontend, rendered in a headless browser with synthetic API fixtures. They are not photographs or generated mockups.

- `dashboard-desktop.png`: desktop dashboard at a 1440 x 1120 viewport.
- `dashboard-mobile.png`: the nutrition section of the responsive web dashboard at a 390px viewport. This is a web UI screenshot, not the native Android app.
- `nutrition-trends.png`: the dashboard's 30-day nutrition chart.

All accounts, device identifiers, health metrics, meals, and dates are fabricated for documentation. The capture environment intercepts API requests and blocks external requests; it does not sign in to a live account or query a production database. The sample date is 2026-10-01 and the timezone is UTC.

Screenshots were visually reviewed for text clipping and browser errors. The capture checks reported no horizontal overflow on desktop or mobile.
