New Health Companion widget collection and app icon.

- Six additional widgets: full-size and 1 × 1 versions of Today's progress, Daily rings and Nutrition average. Existing widgets remain available.
- Purple gradient progress bars, five colored nutrition rings, heart-and-pulse artwork and light/dark surfaces inspired by the supplied reference.
- Average widgets independently support calories, protein, carbs, fat or fiber across 7, 14 or 30 completed nutrition days. Full-size averages show nutrient-specific coverage and the saved date range; today is excluded and unknown history is not drawn as zero.
- New purple gradient heart-and-pulse adaptive launcher icon, including a monochrome themed icon.
- Add widgets from Settings → App preferences → Home screen widgets or the launcher's Widgets menu. Configure each average before pinning, or through its launcher settings.
- Widget appearance follows the app appearance preference. System appearance is refreshed on widget updates; launcher cell dimensions, padding and icon masks vary by device.

No backend API or database migration is required. Widget previews and README images use synthetic data. Production signing remains local; the established signing identity and startup protection are preserved.
